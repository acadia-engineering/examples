# Build Instructions

This example uses [`elm-server-prototype`](https://github.com/acadia-engineering/elm-server-prototype) to run Elm code for the server. Navigate to the `examples/03-users/` directory, and then use the following commands to get it running.

```bash
git clone https://github.com/acadia-engineering/elm-server-prototype.git
bash elm-server-prototype/src/serve.sh
```

This should start a server at [`http://localhost:3000`](http://localhost:3000) that puts everything together.
